# GitHub Pages deployment checklist

- [ ] `.github/workflows/deploy-pages.yml` is at repository root.
- [ ] `package.json` is at repository root.
- [ ] Default branch is named `main`.
- [ ] Repository Settings → Pages → Source is `GitHub Actions`.
- [ ] GitHub Actions are enabled under Settings → Actions → General.
- [ ] The deployment workflow completes with a green check.
- [ ] The published link is opened from Settings → Pages rather than guessed manually.
